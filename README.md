# ouchi-colon-korokoro-race-v3

Ouchi Colon「ころころレース」のHTMLゲームプロトタイプです。

## 起動方法

`index.html` をブラウザで開くとプレイできます。

GitHub Pagesでは、リポジトリのルートを公開対象にすれば `index.html` がそのまま表示されます。

## Phase 1 実装内容

- Vanilla HTML / CSS / JavaScript のみで実装
- `index.html` 1ファイルで動作
- 外部ライブラリなし
- スマホ縦画面 390x844 を基準にしたCanvas描画
- 画像なしで動くCanvas図形ベースのプロトタイプ
- タイトル画面
- 「Ouchi Colon ころころレース」のタイトル表示
- スタートボタン
- 下部メニュー
  - キャラクター
  - コース
  - せってい
  - ランキング
  - おしらせ
- スタート後のレース画面
- スーパーファミコン風の疑似3Dコース表現
- MIKAROを画面下中央に背中向きで表示
- 左右キー、A/Dキー、画面左右タップで左右移動
- 星アイテム取得でスコア加算
- 敵またはブロック接触で大きく減速
- ジャンプボタン、スペースキー、上キーでジャンプ
- ジャンプ中はブロックを回避可能
- HUDに LAP、星数、スピードを表示

## Phase 2 実装内容

- タイトル画面の「キャラクター」ボタンからキャラクター選択画面へ遷移
- 画面上部に「キャラクターせんたく」を表示
- 選択中キャラクターの大きい表示エリアを追加
  - 簡易キャラクター表示
  - 名前
  - 説明文
  - 性能表示（そくど、ハンドリング、おもさ）
- 8キャラクターの一覧カードを2行4列で表示
  - MIKARO
  - ピトコロ
  - マリンカバ
  - フワロ
  - ムーロ
  - カクバケ
  - タコロン
  - ゾノ
- MIKAROを初期選択状態に設定
- 選択中カードに枠とチェック表示を追加
- キャラクターカードのタップで上部表示を切り替え
- 下部に「もどる」「けってい」「せつめい」ボタンを追加
- 「けってい」で選択キャラクターを保存
- 保存したキャラクターの色と簡易性能をレース画面に反映
- キャラクター定義をJavaScript配列にまとめ、将来の画像差し替えに備えた構造に整理

## Phase 3 実装内容

- タイトル画面の「コース」ボタンからコース選択画面へ遷移
- 初期コースを「おうちリビングコース」に設定
- 4コースのカードを表示
  - おうちリビングコース
  - おもちゃばこコース
  - まどぎわカーブコース
  - よるのほしぞらコース
- 各コースに仮情報を表示
  - むずかしさ
  - カーブ
  - アイテム
- 選択中コースに枠とチェック表示を追加
- 「けってい」で選択コースを保存
- 「もどる」でタイトル画面へ戻る
- レース開始時に選択したコース名をHUD下に表示
- まずは「おうちリビングコース」を現在の実レース背景として使用
- コース定義をJavaScript配列にまとめ、将来の画像や背景差し替えに備えた構造に整理

## Phase 4 実装内容

- タイトル画面の「せってい」ボタンから設定画面へ遷移
- 設定画面を追加
- 以下の設定項目を表示
  - BGM：ON / OFF
  - 効果音：ON / OFF
  - 操作方法：タップ / キーボード
  - 難易度：やさしい / ふつう / むずかしい
- 各項目をボタンで切り替え可能
- 設定内容を `localStorage` に保存
- 再読み込み後も保存済み設定を読み込んで表示
- 「もどる」でタイトル画面へ戻る
- 設定項目をJavaScript配列にまとめ、今後の項目追加に備えた構造に整理
