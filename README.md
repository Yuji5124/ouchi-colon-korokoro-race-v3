# ouchi-colon-korokoro-race-v3

Ouchi Colon「ころころレース」のHTMLゲームプロトタイプです。

## 起動方法

`index.html` をブラウザで開くとプレイできます。

GitHub Pagesでは、リポジトリのルートを公開対象にすれば `index.html` がそのまま表示されます。

## Phase 1 実装内容

- Vanilla HTML / CSS / JavaScript のみで実装
- `index.html` 1ファイルで動作
- 外部ライブラリなし
- スマホ縦画面 390x844 を基準にしたCanvas描画
- 画像なしで動くCanvas図形ベースのプロトタイプ
- タイトル画面
- 「Ouchi Colon ころころレース」のタイトル表示
- スタートボタン
- 下部メニュー
  - キャラクター
  - コース
  - せってい
  - ランキング
  - おしらせ
- スタート後のレース画面
- スーパーファミコン風の疑似3Dコース表現
- MIKAROを画面下中央に背中向きで表示
- 左右キー、A/Dキー、画面左右タップで左右移動
- 星アイテム取得でスコア加算
- 敵またはブロック接触で大きく減速
- ジャンプボタン、スペースキー、上キーでジャンプ
- ジャンプ中はブロックを回避可能
- HUDに LAP、星数、スピードを表示

## アセット（画像）について

ゲームは画像なしでも動作します。以下の画像ファイルを配置すると自動的に読み込んで優先表示します。

| 用途 | パス | 推奨サイズ |
|------|------|-----------|
| タイトルロゴ | `assets/ui/title_logo.png` | 横長（例：800×300 前後） |
| 主人公（MIKARO）背面 | `assets/characters/mikaro_back.png` | 正方形（例：256×256 前後） |

- 画像ファイルが存在しない、または読み込みに失敗した場合は既存のCanvas描画・HTML文字表示にフォールバックします
- 画像の読み込み成否はブラウザのコンソールに `[画像]` プレフィックスで出力されます
- `title_logo.png` はオーバーレイ横幅いっぱい（ゲーム画面幅 390px 相当）に引き伸ばして表示します。透明背景PNG推奨
- `mikaro_back.png` は透明背景PNGとして Canvas に重ね描きします。画像底辺をキャラクター足元に合わせて表示するため、縦長または正方形構図を推奨します
