# ouchi-colon-korokoro-race-v3

Ouchi Colon「ころころレース」のHTMLゲームプロトタイプです。

## 起動方法

`index.html` をブラウザで開くとプレイできます。

GitHub Pagesでは、リポジトリのルートを公開対象にすれば `index.html` がそのまま表示されます。

## Phase 1 実装内容

- Vanilla HTML / CSS / JavaScript のみで実装
- `index.html` 1ファイルで動作
- 外部ライブラリなし
- スマホ縦画面 390x844 を基準にしたCanvas描画
- 画像なしで動くCanvas図形ベースのプロトタイプ
- タイトル画面
- 「Ouchi Colon ころころレース」のタイトル表示
- スタートボタン
- 下部メニュー
  - キャラクター
  - コース
  - せってい
  - ランキング
  - おしらせ
- スタート後のレース画面
- スーパーファミコン風の疑似3Dコース表現
- MIKAROを画面下中央に背中向きで表示
- 左右キー、A/Dキー、画面左右タップで左右移動
- 星アイテム取得でスコア加算
- 敵またはブロック接触で大きく減速
- ジャンプボタン、スペースキー、上キーでジャンプ
- ジャンプ中はブロックを回避可能
- HUDに LAP、星数、スピードを表示

## Phase 1.5 変更内容

- タイトル画面を明るいおもちゃ部屋風に調整
- レース背景におうちリビング要素を追加

  - 観葉植物
  - おもちゃ
- MIKAROを黄色ボディ、黒い顔、青い耳の見た目に変更
- 星、敵、ブロックをより丸く可愛い見た目に調整
- ジャンプ台を追加し、踏むと軽くジャンプして加速する挙動を追加
- HUDを明るく読みやすい子ども向けデザインに変更
- ジャンプ中の影を小さく薄くして、浮遊感を強化
- タイトル画面の下部メニューボタンを大きく見やすく調整
